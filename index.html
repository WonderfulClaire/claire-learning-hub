🧭 学习站中枢

把我在 GitHub 上零散的学习站，用「一套后端、多端打通」的思路串成一个学习宇宙。灵感来自秒哒（妙搭）的「共享后端」——只不过这里后端是一份 sites.json，前端是各个静态站。

共享后端：claire-learning-hub / sites.json · 经 jsDelivr 免费分发

这套联动是怎么搭的

① 共享后端：本仓库的 sites.json 是所有站点的唯一数据源（名字 / 链接 / 简介 / 状态）。

② 多端协同：每个学习站注入一段几百字节的导航脚本，运行时从 jsDelivr 拉取 sites.json，在顶部渲染「📚 我的学习站」联动条。

③ 实时同步：改一次 sites.json，所有站的导航条下一次加载就更新——和文章里「小程序下单 → PC 后台实时看到」是同一个逻辑，只是把"订单数据"换成了"站点目录"。

④ 零成本：GitHub Pages（免费静态托管）+ jsDelivr（免费 CDN）+ 纯前端 fetch，不依赖任何付费服务或后端服务器。
